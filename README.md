# RIFT — indie game studio preview

Трёхэкранный демонстрационный сайт независимой игровой студии: кинематографичный игровой key art, редакционный экран о команде, блок услуг и контекстный бриф на запуск проекта.

## Команды

- `npm run dev` — локальный предпросмотр
- `npm run build` — production-сборка
- `npm run lint` — проверка кода
- `npm test` — сборка и проверка серверного HTML
